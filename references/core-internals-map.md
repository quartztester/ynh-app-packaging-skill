# Core-internals map: where the real implementation lives

Read this when a trap/doc claim must be settled from code, or when a skill citation's path no longer exists. Rule of the family: the docs describe intent, the code is truth — but read the code that matches the box you package for.

- ON-DISK FIRST (version-matched, zero drift): the core Python of THIS box is `/usr/lib/python3/dist-packages/yunohost/` (verified YNH 12.1.41.2) — `app.py` (install/upgrade/registration, `APP_FILES_TO_COPY`), `app_catalog.py`, `backup.py`, `permission.py`, `regenconf.py`, `settings.py`, `utils/resources.py` (every `[resources.*]` provisioner: `DatabaseAppResource`, `PortResource`, `InstallDirResource`…), `utils/app_utils.py` (install prechecks, multi-instance logic). Every helper's real body is in `/usr/share/yunohost/helpers.v2.1.d/<domain>` — the only ground truth for helper names/args. Registered app state: `/etc/yunohost/apps/<app>/settings.yml` + the registered script/conf tree (what backup/restore actually executes — traps-lifecycle.md).
- REPOS (github.com/YunoHost/): `yunohost` = core + the helper dirs; default branch `dev`; layout RESTRUCTURED into `src/yunohost/...` and `helpers/helpers.v2.1.d/` (2026-10) — skill citations naming bare `app.py`/`utils/resources.py` refer to the pre-restructure layout and still grep fine by function name. `SSOwat` = the Lua auth layer (`access.lua` is header injection + portal login; reads `/etc/ssowat/conf.json`, ssowat-integration.md). `apps_tools` = catalog + dev tooling (`autoupdate_app_sources`, `catalog_linter.py`, `readme_generator`, `update_app_levels`, `repos_management`); `package_check` and `yunohost_dev` live in their own repos (repo-hygiene.md §apps_tools layout). `yunohost-admin` = web admin UI. `apps` = catalog data (`apps.toml`, `logos/`, `graveyard.toml`, `wishlist.toml`, quality-level machinery).
- CITATION CONVENTION: cite function names, never line numbers (rot at every release; a restructure rots whole paths). State the verified version ("code-read YNH 12.1.41.2") so later readers know the shelf life.
- GitHub `dev` ≠ your box: a behavior verified on `dev` is a hypothesis for YNH 12 until the installed file says so — diff the installed file against the tag matching `dpkg -l yunohost` when it matters.
